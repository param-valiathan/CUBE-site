Open it with the Step 5 card (Behaviour Analysis), or run cube_analyser.py.

The left panel holds the folder controls: Open: Folder loads a Step 3 output folder, Load Mapping loads a saved mapping from clusters to behaviour names, File and FPS select one animal, Group Editor merges clusters into named behaviour groups, Analyse & Preview draws the analysis for the selected file, and Save Results and Save All Results export figures and tables.

On opening a folder, the Analyser finds all *_bout_lengths_hmm.csv files (or the raw ones) in the bout_lengths folder, loads one animal per file, and loads your Step 4 names automatically. The tabs are:

Combined Analysis tab#

The tab shows the animal list on the left and the analysis on the right.

  • Labels. Give every animal a Label 1 (usually its experimental group, for example "Control" or "Drug"), and optionally Label 2 and Label 3 / Animal ID. Group by chooses which label defines the groups. Label 3 is also used to pair the same animal across time points.
  • Run Combined Analysis draws a behavioural fingerprint heatmap (how much of its time each animal spends in each cluster), ethograms (a timeline per animal with coloured bars), and group comparisons. Export Combined saves them.
  • Min bout dur (s) (default 0.3) drops bouts shorter than this from every loaded animal before any statistic is computed, matching the pipeline's own floor. Changing it re-filters the loaded animals immediately, and the value is remembered per source folder. Set it to 0 to see the unfiltered bouts.

Unbiased Analytics tab#

Experimental design (under Statistical Settings, above Group by):

  • Independent groups (default): different animals in each group, for example Control, Treatment A and Treatment B. The overall test is Kruskal-Wallis and the pairwise follow-up is Dunn's test (Mann-Whitney U if scikit-posthocs is not installed). P-values are corrected for the false discovery rate across every cluster and panel shown together, so a star means the same thing on every panel.
  • Repeated measures: the same animals measured at several levels of Group by (for example Baseline, Day 3, Day 7). Give matching animals the same Label 3 / Animal ID at every level. Only animals present at every level are used, and at least 3 matched animals are required. The overall test is a Wilcoxon signed-rank test (2 levels) or Friedman's test (3 or more levels), with pairwise Wilcoxon follow-ups and the same false discovery rate correction. The status bar reports how many animals were matched and how many were excluded.
  • A mixed design (independent groups, each followed over time) is not available.

What the statistics report for each cluster (independent groups): whether the cluster is present in each group at all (a prevalence test, because a cluster that is absent in one group is a different kind of effect from a difference in amount), then, among animals that show it, whether its frequency or duration differs between groups. The result table is exported with the figures.

Behavioral Explorer tab#

Group-level views of sequence structure: Diff Heatmap (difference between transition matrices of two groups), Dwell Violin (distribution of dwell times for each state and group), Sankey (flow of behavioural sequences per group), Group Transitions (transition probabilities per group) Group Networks (circular transition networks per group, above-chance edges only) and Energy Landscape (an occupancy-based landscape over the UMAP embedding: common states are valleys and rare states are peaks).

Group Predictor Tab#

The Group Predictor asks whether the full behavioural profile of an animal can tell its experimental group. It runs three models (based on frequency, total duration and transition probability), each evaluated with leave-one-out cross-validation and a permutation test.

  1. Assign experimental groups in the Combined Analysis tab first.
  2. Click Run Models with the default settings.
  3. Check the permutation p-value (green means significant) and click View on the best model to see its confusion matrix and the features that drive it.

The classifier can be an elastic-net logistic regression, a linear SVM, a shrinkage LDA or PLS-DA (see the target-group section below for when to use each). See GROUP_PREDICTOR_REFERENCE.md for algorithms, figures and interpretation.

Detecting one group among several (target group, contrasts and group statistics)#

With three or more groups the default models try to separate every group from every other. That is often the wrong question. In a baseline / saline / drug design you usually only need to know whether the drug group can be told apart from the other two; telling baseline from saline is irrelevant and only dilutes the result. The Target Group & Contrasts section of the sidebar handles this.

Step by step

  1. Load animals and assign experimental groups in the Combined Analysis tab (Label 1/2/3). Give each animal a Label 3 ID if the same animals appear in several groups (for example baseline and drug recordings of the same mice); CUBE then holds out all recordings of the tested animal together.
  2. Choose Predict by (Combined, or one label factor). The Target group list fills with the groups for that choice. Hover over the list to refresh it after reloading animals.
  3. Pick the Target group (for example Drug). Leave (all groups) for the classic multiclass question.
  4. Keep Pairwise contrasts and Group-level stats ticked. Click Run Models. The three models finish first; the contrast analyses appear below them a little later and the status line says when they are done.
  5. Click Export Results to save every table and every plot (PNG plus CSV).

What each control does, and what to try

Control Default What it does What to try
Target group (all groups) Relabels animals as target vs rest; features, model fit, cross-validation and permutation test all optimise that single contrast (chance becomes 50 %) Set it to the treatment group. Run once with (all groups) too: if the target run is much stronger, the other groups were diluting the signal
Pairwise contrasts on Also tests target vs each other group separately (all pairs when no target is set and there are 3+ groups), with BH-corrected p-values Leave on. If the pooled "target vs rest" result is strong but one pairwise result is weak, the effect is specific to that comparison
Group-level stats on Omnibus usage tests, per-cluster effect sizes, bout-structure features Leave on; it is cheap and answers which behaviours differ
CLR-transform usage off Centred log-ratio of cluster usage (cluster source only). Time spent in clusters sums to 100 %, so one cluster rising forces others to fall; CLR removes that artefact Run once on and once off. If conclusions agree they are robust; if they differ, trust the CLR run when one or two clusters dominate the session
Feature source Individual clusters What the models see Start with clusters. Try Behaviour groups when you have many noisy clusters or want interpretable features; use Mix to combine both
Algorithm Elastic Net Classifier for the three main models. Elastic Net (default): L1 selects, L2 shares weight across correlated clusters, gives probabilities. SVM (linear): same accuracy class, but its probabilities (Platt scaling) are less reliable at small n, so use it mainly as a cross-check. Shrinkage LDA: no tuning, very stable when animals are few; good when many features each carry a little signal. PLS-DA: projects onto 2 latent components, robust to collinearity and common in phenotyping work Start with Elastic Net, then rerun with Shrinkage LDA. If you only have 5-8 animals per group prefer LDA or PLS-DA
Model agreement on Re-fits the same features with all four classifiers (leave-one-out only, no permutations) and compares them Leave on. Conclusions that hold for all four are robust; if only one classifier finds the effect, treat it as fragile
Max contributors 5 Number of clusters/groups the model may use With fewer than 20 animals keep it at 3-5 (roughly at most one feature per four animals). Use All only with 30+ animals
Permutations 199 Resolution of the p-value (smallest possible p = 1 / (n + 1)) 199 while exploring, 999 for a figure you will publish. Pairwise contrasts use the same number

Reading the outputs

  • Classifier contrasts (contrast_summary): one dot per contrast, with the area under the ROC curve (AUC) and its 95 % bootstrap interval. 0.5 is chance. Green means the BH-corrected q is below 0.05. The label also gives balanced accuracy and the minimum detectable accuracy, the accuracy a model must exceed to reach p < 0.05 given your sample size; if your observed accuracy is below it, you do not have the power to claim an effect.
  • Omnibus usage tests (omnibus_usage_tests): the Jensen-Shannon distance and PERMANOVA ask whether the overall distribution of time across clusters differs between groups, before looking at any single cluster. The histograms are the permutation null; the red line is your data. The PCA plot shows animals coloured by group (R² is the share of variation explained by group).
  • Per-cluster effects (usage_effects): a heatmap of Hedges g (effect size, A minus B; about 0.5 is medium and 0.8 is large) for the clusters with the largest effects. * marks q < 0.05 and ** q < 0.01 after FDR correction across clusters. If the same animals appear in more than one group, a mixed model with a random intercept per animal is used; otherwise a Mann-Whitney test. The test column in the CSV says which.
  • Model agreement (model_agreement): balanced accuracy of the four classifiers on the same features, and a matrix of Cohen's kappa between their leave-one-out predictions (1 = identical predictions). Large differences between classifiers mean the result depends on the method; model_agreement_predictions.csv shows, animal by animal, which classifiers got it right.
  • Sequence features (sequence_features, sequence_effects): bouts per minute, mean bout length, bout-length variability, usage entropy, transition entropy (how predictable the next behaviour is) and the share of the dominant cluster. Use them to see whether the drug changes how behaviour is structured, not just how much of each behaviour occurs.

Common situations

Design Suggested setup
Baseline vs saline vs drug, different animals per group Target = Drug, defaults
Same animals recorded at baseline and after drug (repeated measures) Give every recording a Label 3 animal ID. Target = Drug. Cross-validation holds out all recordings of the tested animal and the per-cluster tests use the mixed model
Three or more doses No target; read the pairwise table, or set the highest dose as target
Sex or genotype as well as treatment Set Predict by to one factor at a time, or Combined to treat each combination as a group

Pitfalls

  • Small groups. With fewer than six animals in a group the page shows a warning. Treat results as exploratory and look at effect sizes and confidence intervals, not only p-values.
  • Pooled "rest" is not neutral. Target vs rest assumes the other groups behave alike. If baseline and saline differ, use the pairwise table.
  • Accuracy is only valid for the chosen contrast. Do not quote a target-mode accuracy as if it separated all groups.
  • Selection is optimistic until nested. If you pick the target after seeing the data, or run many configurations, correct for it. Use the nested permutation test for any claim you publish.
  • No signal? Try a larger permutation count only after checking the minimum detectable accuracy; try CLR on; try Behaviour groups instead of clusters; check that the animals' recordings are long enough for stable cluster usage.

What is saved. Export Results (and Save All Results) wait for the background contrast analyses to finish, then write: the model summary, per-animal predictions, confusion matrices, feature importances and permutation nulls; every contrast plot as a PNG with its CSV (contrast_summary, model_agreement plus model_agreement_kappa and model_agreement_predictions, omnibus_tests plus omnibus_pcoa and omnibus_null, usage_effects, sequence_features, sequence_effects); and un_config.json, which records the target group, classifier, feature source, permutations, CLR setting, group sizes, contrasts tested and all warnings, so every saved result can be reproduced and interpreted later.
