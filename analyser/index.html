Open it with the Step 5 card (Behaviour Analysis), or run cube_analyser.py.

The left panel holds the folder controls: Open: Folder loads a Step 3 output folder, Load Mapping loads a saved mapping from clusters to behaviour names, File and FPS select one animal, Group Editor merges clusters into named behaviour groups, Analyse & Preview draws the analysis for the selected file, and Save Results and Save All Results export figures and tables.

On opening a folder, the Analyser finds all *_bout_lengths_hmm.csv files (or the raw ones) in the bout_lengths folder, loads one animal per file, and loads your Step 4 names automatically. The tabs are:

Tab What it is for
Live Preview An ethogram of the selected file that updates as you edit behaviour groups

Group Predictor Whether the behavioural profile can tell groups apart
Paradigm Results Paradigm-specific reports (needs arena tracing)

Combined Analysis tab#

The tab shows the animal list on the left and the analysis on the right.

  • Labels. Give every animal a Label 1 (usually its experimental group, for example "Control" or "Drug"), and optionally Label 2 and Label 3 / Animal ID. Group by chooses which label defines the groups. Label 3 is also used to pair the same animal across time points.
  • Run Combined Analysis draws a behavioural fingerprint heatmap (how much of its time each animal spends in each cluster), ethograms (a timeline per animal with coloured bars), and group comparisons. Export Combined saves them.
  • Min bout dur (s) (default 0.3) drops bouts shorter than this from every loaded animal before any statistic is computed, matching the pipeline's own floor. Changing it re-filters the loaded animals immediately, and the value is remembered per source folder. Set it to 0 to see the unfiltered bouts.

Unbiased Analytics tab#

Experimental design (under Statistical Settings, above Group by):

  • Independent groups (default): different animals in each group, for example Control, Treatment A and Treatment B. The overall test is Kruskal-Wallis and the pairwise follow-up is Dunn's test (Mann-Whitney U if scikit-posthocs is not installed). P-values are corrected for the false discovery rate across every cluster and panel shown together, so a star means the same thing on every panel.
  • Repeated measures: the same animals measured at several levels of Group by (for example Baseline, Day 3, Day 7). Give matching animals the same Label 3 / Animal ID at every level. Only animals present at every level are used, and at least 3 matched animals are required. The overall test is a Wilcoxon signed-rank test (2 levels) or Friedman's test (3 or more levels), with pairwise Wilcoxon follow-ups and the same false discovery rate correction. The status bar reports how many animals were matched and how many were excluded.
  • A mixed design (independent groups, each followed over time) is not available.

What the statistics report for each cluster (independent groups): whether the cluster is present in each group at all (a prevalence test, because a cluster that is absent in one group is a different kind of effect from a difference in amount), then, among animals that show it, whether its frequency or duration differs between groups. The result table is exported with the figures.

The Metric selector in the bar, volcano and heatmap views also offers each cluster's movement signature from cluster_kinematics.csv.

Behavioral Explorer tab#

Group-level views of sequence structure: Diff Heatmap (difference between transition matrices of two groups), Dwell Violin (distribution of dwell times for each state and group), Sankey (flow of behavioural sequences per group), Group Transitions (transition probabilities per group) Group Networks (circular transition networks per group, above-chance edges only) and Energy Landscape (an occupancy-based landscape over the UMAP embedding: common states are valleys and rare states are peaks).

Group Predictor Tab#

The Group Predictor asks whether the full behavioural profile of an animal can tell its experimental group. It runs three models (based on frequency, total duration and transition probability), each evaluated with leave-one-out cross-validation and a permutation test.

  1. Assign experimental groups in the Combined Analysis tab first.
  2. Click Run Models with the default settings.
  3. Check the permutation p-value (green means significant) and click View on the best model to see its confusion matrix and the features that drive it.

The classifier can be an elastic-net logistic regression or a linear SVM. See GROUP_PREDICTOR_REFERENCE.md for algorithms, figures and interpretation.
