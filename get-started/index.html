Get started with CUBE

Install once, then go from a folder of videos to named behaviours.

Requirements

  • Windows 10 or 11
  • Anaconda or Miniconda
  • A CUDA-capable GPU is recommended for DeepLabCut pose tracking (Step 1) and not required for Steps 2 to 5

1. Install

Get the code and create the CUBE conda environment from the file in the repository:

git clone https://github.com/param-valiathan/CUBE.git
cd CUBE
conda env create -f environment.yml
conda activate CUBE

That environment covers feature extraction, clustering, annotation and analysis (Steps 2 to 5). For pose tracking in Step 1, install DeepLabCut into the same environment; for 3D mode also install aniposelib and imageio-ffmpeg:

pip install deeplabcut
pip install aniposelib imageio-ffmpeg   # 3D mode only

DeepLabCut must live inside the CUBE environment, not a separate one. Step 1 fails if it is missing or installed elsewhere.

2. Verify

Check that the environment imports correctly, using the full path to its Python:

"C:\Users\<yourname>\anaconda3\envs\CUBE\python.exe" -c "import umap; print('OK')"

3. Launch

"C:\Users\<yourname>\anaconda3\envs\CUBE\python.exe" cube.py

Two of the steps also run as standalone tools:

# behaviour analyser (Step 5 only)
python cube_analyser.py
# cluster annotator (Step 4 only)
python cube_video_explorer.py

4. Your first run

1Record 2Track 3Discover 4Annotate 5Analyse

Put your videos in one folder

Use .mp4, .avi or .mov files. If you recorded with a synchronised Bonsai rig, run the video corrector first (Step 0).

Track body points

Choose Step 1a for ordinary single-camera video or Step 1b for a calibrated multi-camera rig. If you already have DeepLabCut output files (H5 or CSV), skip straight to Step 2.

Pre-process and discover

Step 2 checks the tracking and keeps the well-tracked body points. Step 3 extracts features, runs UMAP and HDBSCAN, trains the classifier and smooths with a hidden Markov model. Defaults work for most datasets; the user guide explains every setting.

Name the clusters

Step 4 plays example clips for each cluster. Watch a few, give the cluster a name, and move on.

Analyse

Step 5 opens the analyser: ethograms, group comparisons, transitions and figures you can export. Your session is saved after every step; click Load and choose the session file to continue later.
